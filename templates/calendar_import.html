Bring events and to-dos from Google Calendar, Outlook or Apple Calendar into TaskFlow as tasks.

Calendar

Import a file

Export a calendar as an .ics file and choose it here. Every event becomes a task with its date as the due date. Importing the same file again changes the dates instead of making copies.

Follow a calendar

Paste the secret iCal address of a calendar (Google: Settings → the calendar → “Secret address in iCal format”; Outlook: Share → Publish → ICS). TaskFlow reads it every 6 hours.
